풍성한교회 말씀 키링 · 인쇄용 파일

A 원형: 지름 50mm (파일 60×60mm)
B 카드형: 40×60mm, 모서리 반지름 5.5mm (파일 48×68mm)

- 빨간(마젠타) 가는 선 = 재단선(자르는 선). 인쇄하지 않습니다.
- 위쪽 작은 원 = 고리 구멍 (지름 3.5mm)
- 재단선 바깥 2mm = 도련(여유분)
- 뒷면 = NFC 칩 쪽. NFC 칩: NTAG213
- NFC에 넣을 주소: https://bigyws.github.io/Save/churches/pungsunghan/?tag=1

파일 형식
- PDF: 앞면·뒷면 2쪽. 코렐드로우에서 열고 "다른 이름으로 저장 → CDR" 하면 됩니다.
- SVG / EPS: 면마다 한 장씩. 글자를 선(아웃라인)으로 바꿔 두어 글꼴이 없어도 깨지지 않습니다.
- 교회 로고는 사진(그림) 파일에서 가져온 것입니다. 더 선명한 인쇄를 원하면 교회 원본 로고(AI/CDR) 파일로 바꿔 주세요.
