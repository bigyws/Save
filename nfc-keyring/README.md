# 콕태그: NFC 반려동물 추억 키링

강아지·고양이 모양 아크릴 키링 안에 NFC 칩을 넣고, 휴대폰을 대면 반려동물 추억 앨범(사진, 영상, 이야기)이 열리는 상품의 디자인과 웹사이트입니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | **웹 스타일** 판매 페이지 (디자인 선택, 이름 새기기 미리보기, 주문서) |
| `memory.html` | NFC를 대면 열리는 **추억 앨범** (`memory.html?pet=choco`) |
| `app.html` | **앱 스타일** 버전 (홈 피드, 앨범, 스토어, 내 키링 탭, 휴대폰에 앱처럼 설치 가능) |
| `designs.html` | 키링 디자인 시안과 제작 사양 |
| `designs/*.svg` | 인쇄용 키링 디자인 4종 (강아지 앞·뒤, 고양이 앞·뒤) |
| `art.js` | 캐릭터 그림과 키링 디자인을 그리는 코드 |
| `data.js` | 반려동물 정보, 사진 목록, 상품 가격 |
| `store.js` | 사용자가 올린 사진·영상 저장 (지금은 브라우저에 저장) |

샘플 반려동물: 강아지 **초코**(`?pet=choco`), 고양이 **나비**(`?pet=nabi`). 사진은 그림으로 된 예시입니다.

## 지금 되는 것 / 아직 안 되는 것

**되는 것**
- 판매 페이지에서 캐릭터, 이름, 플랜, 수량을 고르면 미리보기와 금액이 바뀌고 주문서가 작성됩니다.
- 추억 앨범에서 사진 크게 보기, 영상 재생, 하트, 링크 복사, 사진·영상 추가가 됩니다.
- 앱 버전에서 반려동물 전환, 탭 이동, 구매 창, 키링 주소 복사가 됩니다.
- 안드로이드 크롬에서는 앱의 "내 키링" 탭에서 NFC 칩에 주소를 직접 쓸 수 있습니다.

**실제 판매 전에 붙여야 하는 것**
1. **결제**: 지금 주문서는 미리보기라 돈이 오가지 않습니다.
2. **사진 저장 서버**: 지금은 올린 사진이 올린 사람 휴대폰에만 저장됩니다. 키링을 대는 모든 사람이 보려면 서버가 필요합니다.
3. **사업자 정보**: 판매 페이지 맨 아래에 상호, 사업자등록번호, 통신판매업 신고번호를 적어야 합니다.

## 실제 판매까지 가는 순서

### 1. 사이트 주소 만들기 (무료)
GitHub Pages를 켜면 `https://bigyws.github.io/Save/nfc-keyring/` 같은 주소가 생깁니다.
저장소 Settings → Pages → Branch를 고르고 Save를 누르면 됩니다.
NFC 칩에는 `https://(내 주소)/nfc-keyring/memory.html?pet=(아이디)`를 씁니다.

### 2. 결제 붙이기 (둘 중 하나)
- **가장 쉬운 방법**: 네이버 스마트스토어나 아이디어스에 상품을 올리고, 판매 페이지의 "주문하기" 버튼을 그 상품 링크로 바꿉니다. 결제, 배송, 사업자 처리를 플랫폼이 대신 해줍니다.
- **직접 결제**: 토스페이먼츠 같은 결제대행(PG)사에 가입하고 결제창을 연결합니다. 사업자등록이 필요하고 서버 코드가 조금 필요합니다.

### 3. 고객 사진 넣기 (둘 중 하나)
- **처음 시작할 때**: 고객에게 사진·영상을 카카오톡이나 구글 드라이브로 받고, `photos/고객아이디/` 폴더에 넣은 뒤 `data.js`에 항목을 추가합니다. 서버 없이 바로 운영할 수 있습니다.
- **주문이 많아지면**: Firebase나 Supabase 같은 서비스를 연결해서 고객이 앨범에서 직접 올리게 합니다. `store.js`만 바꾸면 됩니다.

`data.js`에 새 고객을 추가하는 예시입니다.
```js
bori: {
  kind: "dog", name: "보리", nameEn: "BORI", breed: "푸들",
  birthday: "2021-03-01", together: "2021-05-10", owner: "보리 엄마",
  message: "보리야 사랑해!",
  photos: [{ src: "photos/bori/01.jpg", date: "2024-05-01", caption: "첫 산책" }],
  videos: [], timeline: [],
},
```

### 4. 키링 제작
1. `designs/` 폴더의 SVG 4개를 아크릴 키링 제작 업체(예: 레드프린팅, 오프린트미, 아크릴 굿즈 업체)에 보냅니다. `designs.html`에 업체에 전달할 사양을 정리해 두었습니다.
2. NFC 스티커는 **NTAG215, 지름 25mm** 원형으로 구매합니다(개당 수백 원대).
3. 칩을 넣는 방법은 두 가지입니다. 아크릴 두 장 사이에 칩을 넣는 방식을 업체에 문의하거나, 완성된 키링 뒷면에 칩을 붙이고 에폭시 스티커로 덮습니다.
4. 칩에 주소 쓰기: 휴대폰에 **NFC Tools** 앱(무료)을 설치하고 쓰기 → 레코드 추가 → URL에 주소를 넣고 키링에 휴대폰을 댑니다. 안드로이드라면 `app.html`의 "내 키링" 탭에서 바로 쓸 수도 있습니다.
5. NFC Tools에서 "잠금"을 하면 다른 사람이 주소를 바꿔 쓰지 못합니다. 잠금은 되돌릴 수 없으니 주소를 최종 확인한 뒤 하세요.

### 5. 가격 바꾸기
`data.js`의 `shop` 항목에서 상품 가격, 플랜 추가 금액, 이름 새기기 비용, 배송비를 바꾸면 판매 페이지와 앱에 모두 반영됩니다.
