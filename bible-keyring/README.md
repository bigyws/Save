# 말씀 키링: 오늘의 한 구절

## 시험용 앱 (`index.html`)

휴대폰 브라우저로 여는 앱입니다. 오늘 카드 열기, 읽어주기(휴대폰 목소리), 4개 언어, 두 언어 함께 보기,
보관함·연속 기록, 날짜 바꿔 미리보기(부활절·성탄절·윤년)가 됩니다. 기록은 그 휴대폰에만 저장됩니다.

- `app.html`: 앱 본문 (클로드 아티팩트로 올리는 파일)
- `index.html`: `tools/make_index.sh`로 app.html에 문서 머리말을 붙여 만든 파일 (GitHub Pages용)
- `lib/art.js`: 카드 배경 그림, `lib/daily.js`: 오늘 카드 고르기

GitHub Pages를 켜면 `https://bigyws.github.io/Save/bible-keyring/` 에서 열립니다.
NFC 키링에는 `https://bigyws.github.io/Save/bible-keyring/?tag=1` 을 저장하면 대는 순간 오늘 카드가 열립니다.

## 디자인 초안

키링 안에 NFC 칩을 넣고 휴대폰을 대면 성경 구절이 하루에 한 구절씩 카드로 열리는 앱의 화면 초안입니다.

- `mockups/board.png`: 전체 화면 흐름을 한 장에 모은 보드
- `mockups/screen-1~5.png`: 화면별 이미지 (태그 → Day 1 → Day 2 읽어주기 → Day 3 → 보관함)
- `mockups/lang-board.png`, `mockups/lang-screen-1~5.png`: 다국어 초안 v0.2 (English · 日本語 · 中文 · 두 언어 함께 보기 · 언어/목소리 설정)
- `mockups/board.html`, `mockups/lang.html`: 이미지 원본 (브라우저로 열 수 있음, 일러스트는 코드로 그린 SVG)

교회 마크·로고는 상단 점선 원(LOGO)과 "○○교회" 자리에 들어갈 예정입니다.
구절 본문은 개역한글판 성경입니다(1961년판, 저작권이 끝난 것으로 알려져 있음). 앱에는 출처를 "성경전서 개역한글판"으로 표기합니다.

번역본 초안: 한국어 개역한글, English KJV, 日本語 口語訳, 中文 和合本(简体).

## 365일 말씀 목록 (`data/`)

- `data/verses-365.json`: 앱이 읽을 데이터 (Day 1~365, 월별 주제, 4개 언어 본문과 구절 위치, 그림 주제 제안)
- `data/verses-365.csv`: 같은 내용을 엑셀에서 열 수 있는 표로 (UTF-8)
- `tools/refs.py`: 구절 목록 (여기서 구절을 바꾸고 다시 만듭니다)
- `tools/build.py`: 공개 성경 데이터에서 본문을 뽑아 위 두 파일을 만드는 스크립트
- `tools/motifs.py`: 구절 낱말로 배경 그림 주제를 제안하는 규칙
- `tools/make_xlsx.py`: 목사님 검토용 엑셀 파일 만들기
- `data/calendar.json`: 해마다 바뀌는 절기 날짜 (부활절, 맥추감사절, 추수감사절)
- `lib/daily.js`: 오늘 보여줄 카드를 고르는 코드

### 어떤 날 어떤 카드가 나오나요

- 매년 같은 날짜에 같은 구절 (평년 365일 기준, 1월 1일 = 예레미야애가 3:22-23, 12월 25일 = 누가복음 2:11, 12월 31일 = 사무엘상 7:12)
- 부활절 주일 → 부활절 카드 (마태복음 28:6), 맥추감사절 → 출애굽기 23:16, 추수감사절 → 시편 67:6
- 윤년 2월 29일 → 전도서 3:1, 3월 1일부터는 평년과 같은 구절
- 키링을 처음 댄 날 → 첫 만남 카드(민수기 6:24-26)를 먼저 보여주고 이어서 오늘 카드

### 절기 날짜 바꾸기

부활절은 자동으로 계산됩니다 (2027년 3월 28일). 맥추감사절은 7월 첫째 주일, 추수감사절은 11월 셋째 주일이 기본값입니다.
교회에서 다른 날로 지키면 `data/calendar.json`에서 그 해 날짜를 고치면 됩니다. 예:

```json
"2027": { "easter": "2027-03-28", "harvest": "2027-07-04", "thanksgiving": "2027-11-28" }
```
